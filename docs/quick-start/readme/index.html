Docs/quick start

Quick start — reference pages

The quick start is the walkthrough: decide how you want to use Magpie, install it, set the project up, then isolate the agent, guard what it runs and set up privacy — and go. These are the pages it sends you to when you want more than the step.

Page What it answers
Installation or Adoption? Whether anything gets committed for other people — and who has to agree before you start
Prerequisites What individual skills need before they will run: agent, mail backend, tracker access, and the few skills with extra requirements
Your first run with a family What happens the first time you invoke a family’s skill: the pre-flight stopping, the setup wizard, the configuration it scaffolds, and which files that family actually needs
What each family solves All ten families, the problem each one solves, and what it offers
Other installation methods The pinned snapshot in three flavours, and the self-adoption path a clone of the framework takes

Start at the quick start; come back here when a step raises a question.
