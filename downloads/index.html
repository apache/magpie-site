Verify your download

Always verify the source release using the detached PGP signature: it confirms the artifact was released by an Apache Magpie committer. If the signature verifies, checking the SHA-512 checksum is not necessary. See the ASF's verification guide for the full procedure.

# 1. Import the project's release-signing keys (once)
curl -fsSLO https://downloads.apache.org/magpie/KEYS
gpg --import KEYS

# 2. Verify the detached PGP signature
gpg --verify apache-magpie-0.1.0-source.zip.asc apache-magpie-0.1.0-source.zip

# 3. (optional) Verify the SHA-512 checksum — not needed if the signature checks out
sha512sum -c apache-magpie-0.1.0-source.zip.sha512

How to install

Most people install Magpie from the Apache Magpie Marketplace — two commands, and nothing is committed to your repository. That is the main install: the quick start walks it, and the Marketplace reference covers every supported agent, per-family plugins, pinning, and updates.

Use the signed source release above when you want to install from released sources rather than from the Marketplace — an offline or air-gapped install, or a policy that requires a verified ASF artifact. See Released zip from ASF distribution (offline).

The remaining methods — a pinned snapshot from a git tag or the main branch, and self-adoption for a clone of the framework itself — are in Other installation methods.

Older releases

Only the latest release is supported and mirrored. Previous releases are kept in the Apache archive for reference.
