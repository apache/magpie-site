Verify your download

Download the signature and signing keys above, then verify the source archive before using it.

# Import the project's release-signing keys (once)
curl -fsSLO https://downloads.apache.org/magpie/KEYS
gpg --import KEYS

# Verify the detached PGP signature
gpg --verify apache-magpie-0.1.0-source.zip.asc apache-magpie-0.1.0-source.zip

# Optional: Verify the SHA-512 checksum: not needed if the signature checks out
sha512sum -c apache-magpie-0.1.0-source.zip.sha512
